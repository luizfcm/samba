# Firmware

Esta pasta está reservada para o futuro firmware BLE de validação no ESP32-S3. Atualmente, não contém código executável, configuração de compilação ou integração com o dispositivo.

A simulação disponível está no aplicativo Flutter, na classe `FonteForcaSimulada`. O formato binário aceito pelo decodificador está documentado em [docs/protocolo_ble_v2.md](../../docs/protocolo_ble_v2.md). Não há transmissão BLE implementada.
