# Aplicativo SAMBA

Aplicativo Flutter do SAMBA, identificado pelo pacote Dart `samba_app`.

O código de aquisição e decodificação está em `lib/nucleo/`. O cálculo de métricas e o contrato de processamento por exercício estão em `lib/funcionalidades/medicao/dominio/`. Os testes acompanham essa organização em `test/`.

A tela atual exibe apenas “SAMBA” e “Interface em desenvolvimento”, sem integração com a fonte de força. Os diretórios Android, iOS, Linux, macOS, Web e Windows contêm a estrutura de plataforma gerada pelo Flutter; sua presença não representa validação do SAMBA nessas plataformas.

As instruções de execução e validação estão no [README do projeto](../README.md).
